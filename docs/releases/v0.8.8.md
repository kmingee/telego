# TeleGO v0.8.8

## FreeBSD packages

- Add native FreeBSD `amd64` and `arm64` release archives built with `CGO_ENABLED=0` and `poll_opt,gc_opt`.
- Preserve the Linux `amd64`, `arm64`, and `arm/v7` release archives.
- Publish release assets to `kmingee/telego` and include a Simplified Chinese README in each archive.
- Keep GitHub binary releases working without Docker Hub credentials; publish the existing Docker image tags when credentials are configured.

## Unix / FreeBSD resource safety

- Base the automatic maximum client connection count on FreeBSD's `RLIMIT_NOFILE` soft limit, as on Linux.
- Check the process file-descriptor limits in FreeBSD Middle-End startup logging.
- Close listeners already opened when a subsequent address fails to bind, and close a bound listener when its TCP keepalive configuration fails.
- Add cross-platform listener cleanup regression tests and FreeBSD cross-build CI for `amd64` and `arm64`.

## Documentation

- Add `README.zh-CN.md`, a Chinese documentation index, a FreeBSD installation and permissions guide, and a configuration reference.
- Link the Chinese documentation from the English and Russian READMEs.

## Validation

FreeBSD cross-compilation is checked in CI. Native FreeBSD runtime testing (kqueue, permissions, and descriptor behavior) must still be completed on a FreeBSD host before production deployment.
